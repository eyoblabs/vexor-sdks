## 0.1.0

- Initial release of the official Vexor Python SDK.
- Zero-dependency client using standard library.
- Resumable video upload support via tus protocol.
- Playback token generation and Ed25519 signing integration.
- HMAC-SHA256 cryptographic webhook signature verification.
- Customer storage connection integration (S3 / R2 / GCS).
