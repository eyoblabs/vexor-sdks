# Vexor Client Libraries & SDKs

Official client SDKs and libraries for integrating with the Vexor video infrastructure.

## Available Packages

- **`packages/node-sdk`**: `@vexor-video/sdk` — TypeScript & Node.js client library.
- **`packages/player`**: `@vexor-video/player` — React and Vanilla JavaScript encrypted HLS video player.
- **`packages/vexor-python`**: `vexor-video-sdk` — Python client library.
- **`packages/cli`**: Command-line developer tool for Vexor assets.
- **`packages/vexor-wordpress`**: Vexor Video WordPress plugin.
- **`packages/github-action`**: Automated video upload GitHub Action.

## Installation

### Node.js / TypeScript
```bash
npm install @vexor-video/sdk @vexor-video/player
```

### Python
```bash
pip install vexor-video-sdk
```
